# AgentHunt

**AgentHunt** is a decentralized, open-source crypto airdrop tracker. No server, no account, no wallet connect, no ads, no trackers. Your data stays on your own device.

## Features

- **Airdrop tracker** — track airdrops you join, with task checklists, deadlines and claim status
- **Focus Today** — a 10-second daily hunter summary
- **Deadline Radar** — sorted deadlines with downloadable `.ics` calendar reminders
- **Anti-Scam Check** — interactive GO / CAUTION / NO-GO verdicts using strict screening rules (DappBay Red Alarm, independent score ≥ 65/100, verified contract, gas < $1)
- **Farming Cost Calculator** — with a daily budget rail
- **Daily Hunter Routine**
- **Trending Narratives** — crypto narratives trending on social media, linked to opportunities
- **24 languages** — English by default, with a language selector (including RTL layout for Arabic, Persian and Urdu)

## Decentralized

AgentHunt is a single static HTML file. There is no backend and no database:

- Your airdrops are stored in a JSON file on your own device — export it, back it up, move it anywhere.
- Host it anywhere: GitHub Pages, IPFS, any static host — or just open the file in a browser. It works offline.
- No one can shut it down or lock you out of your own data.

## Use it

Open `index.html` in any modern browser, or visit the GitHub Pages site for this repo.
