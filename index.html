      Truly Decentralized

      NO SERVER · NO DATABASE · NO ACCOUNT

      AgentHunt is a single HTML file. There is no backend that can shut down, no company holding your data, no login. The flow:

      1 · Your Device

      The tracker runs entirely in your phone/laptop browser. Your airdrop data sits in this tab's memory — not in anyone's cloud.

      →

      2 · Your JSON File

      Export produces one .json file that you store yourself (phone, Drive, USB — your choice). Import it on any device and your tracker comes back exactly as it was.

      →

      3 · Hosted by Anyone

      This file can be hosted on GitHub Pages, IPFS, or your own laptop. If one host disappears, copy the file to another — the app runs identically.

      Host it yourself (5 minutes)

      • GitHub Pages: create a public repo, upload this index.html, enable Pages in Settings — done, free.
      • IPFS: upload the file to a pinning service or IPFS Desktop and share the ipfs:// link — no single central server can take it down.
      • Offline: save the file on your phone and open it in a browser — the tracker and forms keep working without internet (the narrative snapshot is baked in).

      Only outbound links to sources (Binance, AirdropBuzz, project sites) need internet.

      Safety Before You Join

      THE SCREENING RULES ALREADY IN USE

      Check first, sign later

      • Score < 65/100 (where an independent score exists) → never report it as “promising”, let alone execute it.
      • Contracts must be verified against the official source (BscScan/Sourcify) and checked on DappBay Red Alarm: if FLAGGED → NO-GO, no exceptions.
      • Small community + no verified token/market → skip. “Free” alone never justifies spending gas.
      • Gas < $1 for free mints; if a preview shows unexpected fund movement or an unlimited approval → stop.
      • Use a dedicated airdrop wallet, never your main wallet. Never type a seed phrase into any website.

      Honest about rumors

      Polymarket: an executive once mentioned a token on a podcast (Oct 2025), but the official help centre (24 Jun 2026) states there is no announced airdrop or TGE yet. Learn from official sources, not X threads.

      Monad & MegaETH are finished: the MON claim closed 3 Nov 2025, MEGA went live 30 Apr 2026 — don't “farm” something whose snapshot has already passed.

      Most farming ends with nothing. Only spend time and money you can afford to lose.
